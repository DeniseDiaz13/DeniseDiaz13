## 🚀 Proyectos destacados

### 🔐 Lastvuln

> **Herramienta CLI para análisis automatizado de vulnerabilidades en dependencias de software.**

Herramienta desarrollada en Python para consultar vulnerabilidades de paquetes mediante la **GitHub Advisory Database** y **OSV API**, facilitando la identificación y análisis de riesgos de seguridad.

**Características:**

* Consulta de GitHub Security Advisories
* Información de severidad mediante CVSS
* Integración con datos EPSS
* Caché local utilizando SQLite
* Procesamiento de respuestas de APIs
* Salida enriquecida para terminal
* Pruebas automatizadas
* Separación entre consulta, procesamiento, presentación y persistencia

**Tecnologías**

`Python` `REST API` `SQLite` `pytest` `Rich` `GitHub API` `OSV API`
